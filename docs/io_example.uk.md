## Робота з водом та виведом у консоль
**Файл [`console_io.cppm`](../src/jizhak/io/console_io.cppm): Модуль `jizhak.io.console`.**
- Підтримує типи рядків на базі `char`, `wchar_t`, `char8_t`, `char16_t` та `char32_t`.
- Повністю підтримує Унікод (Unicode).

### Клас ConsoleBaseIO
- Додає можливості для написання у потік виводу ос
- Дає функції для роботи з роздільником (sep) та символом закінчення (end).
- Додає базові методи друку.

Глобальний об'єкт — відсутній, клас рекомендовано тільки як якості наслідування.

### Клас ConsoleIO
- Додає можливості для отримання даних з потоку воду ос.

Глобальний об'єкт — **`cio`**

### Клас ConsoleErrorIO
- Додає можливості для написання у потік помилок ос замість виводу.

Глобальний об'єкт — **`ceio`**


### print()
Друкує рядок за допомогою fmt::format.
```c++
jzh::cio.print("Друкувати: {}, {}, {}", 5, "5", u8"fїжак!"); // Консоль: "Друкувати: 5, 5, їжак!"
jzh::print("Друкувати: {}, {}, {}", 5, "5", u8"fїжак!"); // Консоль: "Друкувати: 5, 5, їжак!"
```

### println()
Друкує рядок за допомогою fmt::format. Та додає закінчення (_end_), за умовчанням це символ нового рядка.
```c++
jzh::cio.println("Друкувати: {}, {}, {}", 5, "5", u8"їжак!"); // Консоль: "Друкувати: 5, 5, їжак!"\n
jzh::println("Друкувати: {}, {}, {}", 5, "5", u8"їжак!"); // Консоль: "Друкувати: 5, 5, їжак!"\n
```

### print_all()
Друкує декілька рядків використовуючи роздільник (_sep_), за умовчанням це символ пробілу.
```c++
jzh::cio.print_all(5, "5", u8"їжак!"); // Консоль: "5 5 їжак!"
jzh::print_all(5, "5", u8"їжак!"); // Консоль: "5 5 їжак!"
```

### println_all()
Друкує декілька рядків використовуючи роздільник (_sep_), за умовчанням це символ пробілу. Та додає закінчення (_end_), за умовчанням це символ нового рядка.
```c++
jzh::cio.println_all(5, "5", u8"їжак!"); // Консоль: "5 5 їжак!"\n
jzh::println_all(5, "5", u8"їжак!"); // Консоль: "5 5 їжак!"\n
```

### input()
Отримати дані з потоку воду ос.
```c++
jzh::cio.input(); // -> std::string
jzh::cio.input<std::u8string>("test: "); // -> std::u8string, консоль: "test: " 
```

### get_sep()
Отримати роздільник (_sep_).
```c++
jzh::cio.get_sep(); // -> std::string
jzh::cio.get_separator(); // -> std::string
```

### get_end()
Отримати закінчення (_end_).
```c++
jzh::cio.get_end(); // -> std::string
```

### set_sep()
Встановлює роздільник (_sep_).
```c++
jzh::cio.set_sep("5"); // Консоль: cio.sep = "5"
jzh::cio.set_separator("5"); // Консоль: cio.sep = "5"
```

### set_end()
Встановлює закінчення (_end_).
```c++
jzh::cio.set_end("5"); // Консоль: cio.end = "5"
```


## Робота з файлами
**Файл [`file_io.cppm`](../src/jizhak/io/file_io.cppm): Модуль `jizhak.io.file`.**
- Підтримує тільки байти через `std::byte`.

### Клас FileIO
- Додає функції для написання та читання байтів з файлу.
- Додає функції для керування tell.
- Реалізує принцип RAII.

Глобальний об'єкт — відсутній, далі для прикладу буде використано умовний **`fio`**.


### open()
Відкрити файл.
```c++
fio.open(file_path);
fio.open(file_path, fio::om::read_write);
```

### close()
Закрити файл.
```c++
fio.close();
```

### read()
Прочитати байти.
```c++
fio.read(); // std::byte
fio.read(5); // std::vector<std::byte>
```

### write()
Записати байти.
```c++
fio.write(bytes);
```

### tell()
Отримати положення tell.
```c++
fio.tell();
```

### seek()
Встановити tell.
```c++
fio.seek(5);
fio.seek(5, fio::om::current);
```

### is_open()
Чи відкрито файл?
```c++
fio.is_open(); // -> bool
```

### is_readable()
Чи файл є читабельним?
```c++
fio.is_readable(); // -> bool
```

### is_writable()
Чи можна записати у файл?
```c++
fio.is_writable(); // -> bool
```
